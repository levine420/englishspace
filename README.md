# EnglishSpace - Interactive English Learning Website

Website pembelajaran bahasa Inggris interaktif yang fokus pada Simple Present Tense dan Daily Activities.

## Features

- 📚 **Materials**: 20+ vocabulary tentang daily activities dengan grammar Simple Present Tense
- 📝 **Practice**: 10 soal pilihan ganda + 3 latihan menyusun kalimat
- 📊 **Evaluation**: Tracking hasil quiz dengan koreksi detail dan link ke materi
- 👤 **Profile**: Halaman profil developer

## Tech Stack

- HTML5
- CSS3 (Vanilla CSS dengan CSS Variables)
- JavaScript (Vanilla JS)
- Google Fonts (Inter)

## Local Development

1. Clone repository ini
2. Buka `index.html` di browser
3. Atau gunakan live server untuk development

## Deployment

Website ini di-deploy menggunakan Vercel.
